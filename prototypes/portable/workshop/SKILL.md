# Workshop — portable candidate

Advance the requested result, not the number of methods used. Begin with native reasoning and existing trusted tools. Preserve the original goal, required constraints and frozen tests. Reuse valid work; do not repeat completed work just to follow a procedure.

## Select only useful methods

Read the relevant reference when its specific problem arises; there is no mandatory order or minimum number. Combine, repeat, replace or omit methods as the result changes. Do not load every reference by default. If a named method is requested, read its relevant reference directly; do not load an unrelated group.

- **[Structure](references/structure.md)** — formalization, invariants and counterexamples (AXIOM, LANTERN).
- **[Representation](references/representation.md)** — reframing and adaptive observation (PIVOT).
- **[Discovery](references/discovery.md)** — canonical sources, missing evidence and transferable methods (SCOUT).
- **[Execution](references/execution.md)** — implement the smallest complete solution, coordinate dependent work, recover from failures, verify the actual deliverable (FORGE, ORBIT, SENTINEL).
- **[Continuity](references/continuity.md)** — recover prior work, preserve original ideas and dependencies, avoid stale reuse, resume interrupted work (ATLAS, CACHE, TRACE, NAPKIN).
- **[Transition](references/transition.md)** — interface changes, regime equivalence and legal resumption (ADAPTER, HARBOR, STEWARD).
- **[Authoring](references/authoring.md)** — evidence-bound communication, editing and comparison (RHETOR, HUMANIZER, KWRITE).
- **[Judgment](references/judgment.md)** — compare rivals, integrate branches, respect claim scope, evaluate acceptance and stop or redirect (PRISM, MOSAIC, COURT, RAVEL).

For a compound task, identify the missing intermediate result, not a list of skills. Choose a next action that changes a meaningful decision or completes a necessary deliverable. Compare its benefit, cost and constraints with direct work; use 0–1 estimates if useful, never as measured probabilities. Execute feasible authorized actions and inspect results. If a new result changes the bottleneck, reconsider only the affected work. Stop when the requested result is complete or further work cannot justify its cost; expose required blockers instead of silently replacing the task.

Output the requested result first. State material changes, verified outcomes, limitations and next useful action when relevant. Do not invent tool access, results, sources, delivery or scientific authority. No ceremonial reviewer simulation, fixed pipeline, or private reasoning record.
