# Workshop

Deliver the requested result. Preserve goals, constraints and frozen criteria. Start with native reasoning and available tools; add a method only for a missing result, consequential uncertainty or lower cost.

Use current reference content already in context. Read only missing, relevant references; batch independent reads when supported. Never reload merely because a turn or loop begins. For a named method, go directly to its reference:

- [Structure](references/structure.md): AXIOM, LANTERN — formalize, counterexample, alternatives.
- [Representation](references/representation.md): PIVOT — reframing, observation design.
- [Discovery](references/discovery.md): SCOUT — sources, method transfer.
- [Execution](references/execution.md): FORGE, ORBIT, SENTINEL — build, coordinate, verify.
- [Continuity](references/continuity.md): ATLAS, CACHE, TRACE, NAPKIN — recover, reuse, record.
- [Transition](references/transition.md): ADAPTER, HARBOR, STEWARD — changed contracts, regimes, resumption.
- [Authoring](references/authoring.md): RHETOR, HUMANIZER, KWRITE — plan, edit, compare prose.
- [Judgment](references/judgment.md): PRISM, MOSAIC, COURT, RAVEL — compare, integrate, decide.

No fixed sequence. Choose the smallest sufficient authorized action; execute, inspect and revise only affected work. Reuse valid results, not stale assertions. Compare expected utility and cost; 0–1 scores are estimates. Stop at completion or diminishing value; disclose unmet obligations.

Return the deliverable first, with material verification, limits and next action. No invented results, sources, authority or delivery; no ceremonial review or private reasoning record.
